# 50 стилів · RTEM Design

Статична галерея 50 AI-стилів: окремі сюжети, порівняння до/після, авторські англомовні промпти, пошук і фільтри. Український інтерфейс, акцент `#FF6A28`.

## Локальний перегляд

Запустіть `python3 -m http.server 8080` у цій папці й відкрийте `http://localhost:8080`.

## GitHub Pages

Публікуйте корінь гілки `main` через Settings → Pages → Deploy from a branch. Сайт не потребує збірки, сервера або API-ключів.

`styles.js` містить контент, `01.webp`–`50.webp` — оптимізовані пари зображень. Кожна пара має оригінал ліворуч і стилізацію праворуч; інтерфейс показує потрібну половину й накладає їх у порівнянні.

Зображення — AI-ілюстрації. Точне відтворення результату залежить від генератора та вихідного зображення.
